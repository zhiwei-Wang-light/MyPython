## 2.word2vec

### word2vec是一种向量表示方法,训练方式有两种包括CBOW与skip-grams,word2vec不能表达多个意思,是静态的,具有上下文信息

## 3.自注意力机制

### 注意力与RNN的区别:注意力适用于长距离序列,并行计算,但是计算开销大。RNN适用于短距离序列,结构简单,但可能梯度消失或者梯度爆炸

## 4.transformer为什么使用层归一化不使用批归一化

### transformer通常处理变长的序列,批归一化依赖于整个批次的统计信息,在序列长度不一致时会导致问题。层归一化对每个样本独立进行归一化,避免了批归一化对批次的依赖

## 5.多头注意力机制

### transformer使用了8个头,在最后使用concat进行拼接,然后使用线性层进行降维,多头注意力机制解决了单头只能提取单一的特征的问题,能够提取

### 多种特征,最后再进行融合

## 17.生成模型中的采样类型

### 采样策略决定了如何从输出概率分布中选择下一个生成的元素。常见的方法有top-k,top-p,核采样,top-k重要的是在前k个中随机选择一个作为输入,top-p指从累积概率达到p的候选项中进行选择

## 18.光束搜索

### 光束搜索是一种启发式搜索算法,每一时刻均保留得分最高的前k个候选项,再有前k个候选项作为下一时刻的输入,找到下一时刻所有可能性输出的前k个候选项,时间复杂度

### O(L*b*N),L序列最大长度,b光束宽度,N每一步可以生成的候选词汇数量。

## 24.PPO训练日常问题

### 平均奖励：主要目标是在 RL 训练期间最大化模型获得的奖励。目标 KL 散度：KL 散度（Kullback-Leibler 散度）衡量两个概率分布之间的差异。在 RL 训练的背景下，我们使用它来量化当前模型和参考模型之间的差异。

### 理想情况下，我们希望将 KL 散度保持在 0 到 10 之间，以确保模型生成的文本与参考模型生成的文本保持一致。

### 针对奖励模型进行优化的 RL 模型可能会学习到产生高奖励但并不代表良好语言的模式。这可能导致极端情况，例如模型生成包含过多感叹号或表情符号的文本以最大化奖励。在某些最坏情况下，模型可能会生成与自然语言完全无关的模式，但仍然获得高奖励，类似于对抗攻击。

### 为了解决这个问题，我们在奖励函数中添加了一个基于当前模型和参考模型之间 KL 散度的惩罚项。通过这样做，我们鼓励模型保持接近参考模型生成的输出。
